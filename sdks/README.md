# SDKs

A protocol's non-Rust SDK is **generated types on a hand-written runtime**, not
a hand-rolled JSON-RPC loop per protocol per language.

| Half | Where it lives | Who writes it |
|------|----------------|---------------|
| Framing, transports, serve loop, symmetric peer, handshake | `sdks/python/`, `sdks/typescript/` | written once, by hand |
| Wire types, method names, capability tokens, direction table | generated by `lanok gen` | nobody |

Each language ships both shapes Rust has: a serial `Server` for a small tool
server, and a symmetric `Peer` that can be **either end** of a connection,
including the reverse direction.

```bash
lanok gen python     --schema path/to/schema/v1 --out sdks/python/lanok/_generated_myproto.py
lanok gen typescript --schema path/to/schema/v1 --out sdks/typescript/src/generatedMyproto.ts
```

Add `--check` to fail instead of writing. That is the drift guard: a protocol
change that does not regenerate its SDKs fails CI rather than shipping a
mismatch.

## Why the split is where it is

The runtime half is the hard part, and it is identical for every protocol:
classifying a line by its fields, keeping `jsonrpc: "2.0"` outbound and optional
inbound, answering the handshake, skipping junk instead of dying on it, and
streaming notifications while a request is open. Getting that right once per
language and then reusing it is the entire argument for this kit existing.

The generated half is the part that is genuinely different per protocol, and it
is mechanical, so no human should be writing it.

## Proof rather than claim

Two checks, both in CI.

The committed conformance suite runs against all three server implementations:

```bash
just conform
```

And every client runs against every server, nine combinations, each a full
exchange including a reverse request:

```bash
just matrix
```

```
rust         client -> rust         server  ok
rust         client -> python       server  ok
rust         client -> typescript   server  ok
python       client -> rust         server  ok
...
all 9 combinations passed
```

If a language could only serve, or only drive, a row or a column would be
missing.
